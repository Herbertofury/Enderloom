## v4 hardening added

- JVM bytecode instruction scanning for field/method call sites rather than constant-pool presence alone.
- Static-vs-instance linkage validation.
- Interface-vs-class invocation validation.
- Java-runtime-aware Multi-Release JAR class selection (`runtime_java=25` for Minecraft 26.3).
- Recognized nested-JAR indexing without executing classes.
- Exact target-index SHA-256 input identity.
- Strict guard rejection of stale-schema, wrong-runtime, identity-less, or parse-damaged target indexes.
- Declared-owner-only proof for Access Wideners/Class Tweakers/Access Transformers, preventing inherited-member false passes.
- Modern MixinExtras selector coverage plus `@Overwrite` structural resolution.
- Exact common reflection/MethodHandle/Forge reflection-helper source resolution.
- Packaged Fabric entrypoint, Mixin config/class/plugin, access-widener, nested-JAR and ServiceLoader-provider checks.
- Candidate runtime-class shadowing and Java classfile-level checks.

## Adversarial regressions now proven

The self-test deliberately verifies rejection of:

- inherited member named on the wrong access-transformer owner;
- missing literal reflection members/classes;
- static -> instance ABI drift with identical owner/name/descriptor;
- interface -> class drift with identical owner/name/descriptor;
- stale/wrong-runtime target indexes;
- missing packaged Fabric entrypoint/Mixin/AW/nested JAR declarations;
- missing ServiceLoader providers;
- historical Mixin selector ambiguity;
- stale LambdaMetafactory SAM linkage.

It also proves Java 25 vs Java 17 Multi-Release selection and modern MixinExtras/`@Overwrite` resolution.

## Runtime boundary

These gates are intentionally pre-runtime evidence. A static PASS still does not replace required dedicated-server, native-client/integrated-server, Mixin PREPARE/APPLY, gameplay, visual, networking, save/config, or restart proof.
