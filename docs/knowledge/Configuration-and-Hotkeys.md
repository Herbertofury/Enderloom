[**CONFIG-02**](Checklist.md#config-02) - Apply scoped profiles and performance-linked changes transactionally, validate diffs, diagnose bad config without blanket deletion and preserve user intent across versions.

[**CONFIG-03**](Checklist.md#config-03) - Inventory full bindings with owner/default/current/context, find real conflicts, rebind/reset and manage profiles/import/export/migration with correct runtime/UI integration.

### Data, functions and command debugger

[**CONFIG-04**](Checklist.md#config-04) - Provide target-aware parser/diagnostics, execution traces/watches/state diff, supported breakpoint-like behavior, command-block graphs and deterministic regression generation.

### Scripted modpack logic

[**CONFIG-05**](Checklist.md#config-05) - Integrate relevant KubeJS/CraftTweaker/Bedrock script bridges, source/owner links and safe tested changes; never run untrusted scripts merely to inspect inputs.

### Progression and softlock intelligence

[**CONFIG-06**](Checklist.md#config-06) - Analyze quest/recipe/loot/unlock dependencies, detect reachability and progression traps, explain causes and verify fixes in actual gameplay.
