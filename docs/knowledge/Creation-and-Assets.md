# Authoring and real assets

[Home](Home.md) / [Checklist](Checklist.md) / [Architecture](Architecture.md) / [Ecosystem](Ecosystem.md) / [Source map](Source-Map.md)

> Visual creation and expert code operate on the same editable project.

### Arbitrary native mod creation

[**MAKE-01**](Checklist.md#make-01) - Create blank, starter or imported projects with functioning content, stable identity, build/test setup and source escape hatches; templates and block/item examples are not the ceiling.

### Safe visual and code round-tripping

[**MAKE-02**](Checklist.md#make-02) - Visual properties, source editor, language tooling and semantic representation stay connected; user code/unknown syntax remains recoverable without silently losing build or conversion behavior.

### Items, blocks and equipment editors

[**MAKE-03**](Checklist.md#make-03) - Author materials, states, tools, armor, equipment and inventories with target-aware properties, references and in-game proof.

### Entities, bosses and gameplay graphs

[**MAKE-04**](Checklist.md#make-04) - Author entities, AI/events/procedures, interaction, combat, progression and custom systems with meaningful behavior and network/persistence validation, not empty registrations.

### Recipes, loot, tags and data editing

[**MAKE-05**](Checklist.md#make-05) - Use visual recipes and structured validated data editors, reference navigation, error repair, target schemas and deterministic datagen without dropping unknown fields.

### World, biome, structure and dimension authoring

[**MAKE-06**](Checklist.md#make-06) - Preview and edit world content with source-linked generation rules, safe native testing and full worldgen/structure/dimension semantics.

### Model, UV and texture fidelity

[**MAKE-07**](Checklist.md#make-07) - Support relevant model codecs, cubes/planes/meshes, hierarchy, pivots/locators, per-face rotated/flipped UVs, texture layers and pixel-correct editing without geometric simplification.

### Animation, Molang, effects and audio

[**MAKE-08**](Checklist.md#make-08) - Timeline/scrubbing, easing/interpolation, expressions/scopes, locators, sounds/particles/custom tracks and real audio playback preserve behavior, timing and thread isolation.

### Reference and concept reconstruction

[**MAKE-09**](Checklist.md#make-09) - Lawfully ingest images/GIFs/models/server resources, distinguish observed/inferred/authored facts, reconstruct from multiple views/times, preserve intended Minecraft style and verify native visuals.

### Compound content and ecosystem integration

[**MAKE-10**](Checklist.md#make-10) - Build interacting content families with version-specific integrations, edit/play/rebuild and convert them; a decorative block or asset pack alone is not a complete created mod.

### Real preview and native comparison

[**MAKE-11**](Checklist.md#make-11) - Viewport orbit/pan/zoom, orthographic/perspective, texture/UV/material inspection and native captures use actual project assets; clearly separate preview approximations from native runtime proof.
