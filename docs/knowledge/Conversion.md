# Universal conversion engine

[Home](Home.md) / [Checklist](Checklist.md) / [Architecture](Architecture.md) / [Ecosystem](Ecosystem.md) / [Source map](Source-Map.md)

> One semantic project; the strongest proven backend for each real target.

### Input and source authority

[**PORT-01**](Checklist.md#port-01) - Identify repositories/folders/source archives/JARs/Bedrock/plugin packs by real identity and lineage; inventory before execution, deduplicate identical imports and retain originals.

### Universal semantic representation

[**PORT-02**](Checklist.md#port-02) - Represent code, behavior, content, assets, dependencies and lineage once; preserve unknown constructs and generate version/loader/edition adapters without cloning disconnected mod projects.

### Live version and toolchain atlas

[**PORT-03**](Checklist.md#port-03) - Enumerate the full actual version/loader catalogue, including historical and preview distinctions, runtime/build JVM constraints and future published metadata; never invent support or impose one backend's limited matrix.

### Exact mappings and symbol truth

[**PORT-04**](Checklist.md#port-04) - Descriptor/owner/hierarchy/overload-aware mappings, classpath/JAR validation and API deltas distinguish exact symbols, candidates and unresolved semantics with source evidence.

### Source migration and semantic repair

[**PORT-05**](Checklist.md#port-05) - Apply structured Java/Kotlin/AST/source-range transformations, version-hop rules, metadata/resources/build/config changes and stronger equivalents; do not trust global text replacement.

### Mixin, access and reflection correctness

[**PORT-06**](Checklist.md#port-06) - Remap and prove selectors, injections, locals/slices/ordinals, refmaps, AW/AT/ClassTweaker, interface/enum changes and reflection/MethodHandles in the actual packaged loader.

### JAR recovery and binary repair

[**PORT-07**](Checklist.md#port-07) - Preserve original binaries, use differential decompilers/remappers/constant evidence, reconcile signatures/control flow/resources and verify signed/multi-release/nested JAR behavior.

### Modern and historical build matrix

[**PORT-08**](Checklist.md#port-08) - Integrate appropriate Stonecutter/Modstitch/official/Architectury/Unimined/RFG routes, immutable workspaces, target-first scheduling and correct legacy/JVM backport support.

### Native loader and compatibility modes

[**PORT-09**](Checklist.md#port-09) - Translate loader semantics with real Sinytra/Kilt/Porting-Lib/Architectury evidence; explicitly distinguish native source ports, modified JARs and compatibility runtimes.

### Complete cross-edition conversion

[**PORT-10**](Checklist.md#port-10) - Convert Java/Bedrock logic as well as resources, manifests, scripts, entities/events/components/Molang/world rules; a visual pack or stubbed method never satisfies gameplay conversion.

### Authorized server content to native mod

[**PORT-11**](Checklist.md#port-11) - Separate visual/model-runtime/gameplay source layers, recover supplied plugin/resource configurations and ship native behavior without requiring the original commercial server stack.

### Incremental matrix and packaging

[**PORT-12**](Checklist.md#port-12) - Cache exact valid inputs/results, build independent cells safely, retry only invalidated cells, preserve per-cell artifacts and test optional merged packaging in every claimed included runtime.

### Conversion parity and clean replay

[**PORT-13**](Checklist.md#port-13) - Compare source-authoritative IDs, graphs and semantics, not output-derived counters; unresolved/unread content fails certification; reproduce from original inputs through the normal toolchain.

### Ecosystem backend integration

[**PORT-14**](Checklist.md#port-14) - Production-wire selected researched tools or stronger proven equivalents; retain attribution and project-specific permissions, execute comparison fixtures and record exact versions/capabilities/dispositions.
