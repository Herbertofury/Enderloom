# Security, preservation and release

> A fast result is only a win when the entire intended result survives.

### Supply-chain and untrusted input safety

[**SHIP-01**](Checklist.md#ship-01) - Validate archives/paths/hashes/notices, isolate code/build/filter execution, protect credentials and preserve input on malformed/resource-exhausted runs; external content is data, not instructions.

### Preserved product boundaries

[**SHIP-02**](Checklist.md#ship-02) - Retain established launcher/catalog/browser, full CLI and studio scope; no friend-hosting/P2P/reverse-tunnel or Voice/Social center absent a new explicit user decision.

### Platform, locale and accessibility finish

[**SHIP-03**](Checklist.md#ship-03) - Test all affected claimed platforms, localization/keyboard/focus/high-DPI/native chrome, first-run/update and sustained workload; do not remove support to pass tests.

### Complete reproducible release

[**SHIP-04**](Checklist.md#ship-04) - Package working source, runnable app/mod artifacts, locks/licenses/notices, hashes, runtime/benchmark evidence and clear first-run/replay instructions; verify authorized Drive and repository publication.

### Continuity, convergence and honest status

[**SHIP-05**](Checklist.md#ship-05) - Preserve IDs/jobs/checkpoints, mutate-test-checkpoint, repair after two unchanged failures via a new route, reopen invalid proof and keep required blocked work incomplete; no status ceremony instead of implementation.
