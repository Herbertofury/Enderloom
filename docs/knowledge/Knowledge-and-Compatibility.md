### Premium in-app Wiki

[**KNOW-01**](Checklist.md#know-01) - Build source-grounded project/mod documentation with real media, diagrams, config/hotkey/recipe/progression/evidence links, exports and useful maintenance; this is separate from the GitHub Wiki documenting development.

### Why installed and contextual explanations

[**KNOW-02**](Checklist.md#know-02) - Answer dependency/choice/score/change questions from the canonical graph with evidence, distinguish facts/inferences and link to exact actionable objects.

### Adaptive ecosystem contracts

[**KNOW-03**](Checklist.md#know-03) - Select behavior-driven integrations for storage/backpacks/accessories/recipes/Create/Apotheosis/food/guides/tooltips/scripts/animation/energy/quests/worldgen/rendering, not arbitrary mandatory dependencies.

### Compatibility execution and matrix

[**KNOW-04**](Checklist.md#know-04) - Generate version-specific contract fixtures, provider-present/absent tests and exact target evidence; compiled API calls or similar names do not prove equivalent behavior.

### Source refresh and typed extensions

[**KNOW-05**](Checklist.md#know-05) - Keep provider/tool/schema/contract registries extensible, versioned, cached and on-demand with pagination/rights/health/provenance and unknown-versus-absent states; no hidden polling watchdog.
