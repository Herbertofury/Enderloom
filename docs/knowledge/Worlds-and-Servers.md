# Worlds, servers and migration

[Home](Home.md) / [Checklist](Checklist.md) / [Architecture](Architecture.md) / [Ecosystem](Ecosystem.md) / [Source map](Source-Map.md)

> Preserve Forever Worlds, external ownership and every meaningful migration field.

### World browser and safe editing

[**WORLD-01**](Checklist.md#world-01) - Inspect/import/rename/present worlds, NBT/data packs/maps/regions where supported, associate exact instance/runtime and use safe staged edits rather than live experimentation.

### Backups, recovery and Forever Worlds

[**WORLD-02**](Checklist.md#world-02) - Create verified immutable snapshots, diagnose ticking data/world failures, recover/recreate faithfully and test restore/restart; never prune/delete dimensions or data to manufacture repair.

### Whole-modpack migration

[**WORLD-03**](Checklist.md#world-03) - Inventory mods/configs/hotkeys/scripts/quests/wiki/worlds/dependencies, plan native equivalents and version transitions, preserve intent and prove the migrated pack with rollback.

### Cross-edition world conversion

[**WORLD-04**](Checklist.md#world-04) - Use exact-pair Chunker/je2be or stronger adapters, reconcile blocks/states/items/entities/dimensions/metadata and real loading; world conversion is not mod-code conversion.

### Real server management

[**WORLD-05**](Checklist.md#world-05) - Manage/import/install accepted server software, EULA consent, properties/console/RCON/commands/players/backups/processes and explicit maintenance automation through GUI/CLI parity.

### Network, proxy and plugin semantics

[**WORLD-06**](Checklist.md#world-06) - Diagnose supported protocol/proxy/server issues and convert authorized plugin/threading behavior with real ownership/scheduler/teleport/network proof; no fabricated universal compatibility.
